Privacy Policy

Effective date: October 13, 2026

drive-mirror-personal processes data for the owner's personal file management.

Data access and use

With the owner's authorization, the tool processes file contents and metadata for transfers, synchronization, file management, integrity checks, and troubleshooting. The Google Drive permission it requests allows reading, creating, updating, and deleting files.

Storage and sharing

Files are stored in owner-controlled systems and authorized Google Drive locations. Credentials and operational data, including logs, file lists, and caches, are kept on owner-controlled storage until removed manually or by configured cleanup. Google connections use HTTPS, and local access is restricted. Data is exchanged with Google for these operations, not sold or used for advertising.

Control and deletion

The owner can delete stored data and can revoke access through Google Account connections. Revoking access does not itself delete stored data.

Google API policy

The tool's use and transfer of Google API data complies with the Google API Services User Data Policy, including Limited Use requirements.
